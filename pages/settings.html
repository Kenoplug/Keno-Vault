Legacy Mode (Dead-Man's Switch)
Secure transfer to your heir
Pro
How Legacy Mode Works
If you don't log in for 180 consecutive days, Keno Vault will automatically send your encrypted vault data to your designated heir's email. The data is AES-256 encrypted — only someone with your backup password can open it.
⬡ Pro Feature

Upgrade to Pro to configure Legacy Mode.

Note: Ensure your heir knows your backup password to decrypt the transferred data. The email will include encrypted JSON — they'll need it opened with Keno Vault's import tool.

Quick SQL Reference
Run these in Supabase SQL Editor if needed
-- Activate Growth or Pro:
INSERT INTO subscriptions (email, plan, status, provider)
VALUES ('user@email.com', 'growth', 'active', 'manual')
ON CONFLICT (email) DO UPDATE
SET plan='growth', status='active', updated_at=now();

-- Remove subscription:
UPDATE subscriptions
SET plan='free', status='inactive', updated_at=now()
WHERE email='user@email.com';
